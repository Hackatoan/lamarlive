# lamarlive

Static shell for **lamarlive.hackatoa.com** — the gallery of sites built by Lamar's
Discord `/build` command.

**Hybrid deploy:** the GHCR image (`ghcr.io/hackatoan/lamarlive`) ships only the static
shell (`site/index.html`). The dynamic parts stay as host mounts so `/build` keeps working:

- `/opt/homelab/lamarlive/u`  → `/usr/share/nginx/html/u`  (user builds, written by lamarlive-builder)
- `/opt/homelab/lamarlive/sitemap.xml` → `/usr/share/nginx/html/sitemap.xml` (regenerated by `gen-sitemap.sh` on the host)

Push to `main` → CI builds/pushes the image → Watchtower redeploys. `gen-sitemap.sh` is
kept here for reference but runs on the host, not in the image.
